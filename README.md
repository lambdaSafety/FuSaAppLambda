대메뉴는 아이콘과 이름으로 표시한다. **안전 분석 → FMEA**에서 행을 추가하고 구조, 엘리먼트, 기능, 고장 모드, 영향, 원인, 예방·검출 관리, S·O·D(1~10), AP(H/M/L)를 직접 입력한다. 한 계정의 워크시트는 현재 브라우저에 자동 저장된다.

**확률과정·시뮬레이션 → 몬테카를로 시뮬레이션**에서 두 독립 입력을 샘플링한다. 표본을 추가하며 누적 평균, 출력 분포, 임계치 초과 비율을 비교한다.

### MTTF, MTBF 실습

단일 수리 이벤트와 비수리 OR·AND 게이트를 선택해 MTTF, MTBF, 유효 MTBF를 계산한다. 결과 아래에서 임무 시간에 따른 누적 생존 면적, 고장 발생 빈도, 누적 고장 확률을 확인할 수 있다. 모델별 수식과 FTA 호출 예시는 [ExpoDist_API.md](ExpoDist_API.md)에 정리했다.

공학 통계의 **추론/검정 분포**, **이산/횟수 분포**, **수명/고장 분포**에서 모수와 기준값을 바꾸고 계산한다. 누적확률 곡선과 기준점이 직전 계산에서 어떻게 이동했는지 비교할 수 있다.

세 분포 소메뉴는 연속분포의 PDF 또는 이산분포의 PMF와 CDF를 나란히 표시한다. 한 번의 계산으로 두 그래프와 기준값을 함께 갱신한다.

공학 통계에서 벤 다이어그램, 조건부 FTA, 베이즈 갱신, 큰수의 법칙과 일표본 평균 검정을 실습한다. 확률과정에서는 표본경로, 포아송 도착, 랜덤 워크 및 수리 가능한 이중화 시스템의 첫 정지를 비교한다.

리스크 결정의 여섯 소메뉴는 표준별 판정표와 선택 근거를 제공한다. [구현 단계와 검증 예시](./risk_tables.md)
